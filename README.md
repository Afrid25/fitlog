# FitLog

FitLog is a dark, focused workout library for choosing lifts, building today's plan, and tracking completed work. It uses the FitLog API for workout data and keeps plan and saved workouts available after a page reload.

## Technologies

- Next.js 16 App Router
- React 19 and TypeScript
- Tailwind CSS 4 with daisyUI
- Lucide React icons
- FitLog REST API
- Browser localStorage for plan persistence

## Features

1. Responsive workout library with image cards and muscle-group tags.
2. Workout detail pages with equipment, difficulty, sets, reps, duration, calories, rating, and instructions.
3. Add workouts to a five-lift daily plan or save them for later.
4. Live Plan and Saved counters in the global navigation.
5. My Plan dashboard with exercise, minutes, and calorie metrics.
6. Sort controls for duration, calories, and rating in My Plan.
7. Mark-as-done and remove actions with dark themed toast feedback.
8. Responsive loading states and a custom 404 page.
